# ESP32 Fan Controller

C++ translation of `thermal-sim/src/core/engine/fanController.ts`.

## Files

- `fan_controller.h` — Header-only controller. Include in your ESP32 sketch.

## Usage

```cpp
#include "fan_controller.h"

ControllerState state = {};  // zero-initialized
SensorReadings readings;

void loop() {
  readings.coreTemp    = readThermistor();     // °F
  readings.avgOxygen   = readO2Sensor();       // fraction 0-0.21
  readings.avgMoisture = readMoistureProbe();  // fraction of FC 0-1
  readings.ambientTemp = readDHT22();          // °F

  FanOutput output = computeFanControl(readings, state);

  setRelay(output.onSeconds, output.offSeconds);
  setServo(output.gatePct);
}
```

## Lookup Table Fallback

When sensors fail, use `FALLBACK_LOOKUP[]` (ambient temp → fan settings).
Generated by `thermal-sim/test/seasonValidation.test.ts`.
